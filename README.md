# Лабораторная работа № 10

## Условие задачи

Составить программу, которая для заданной пользователем фигуры — равностороннего треугольника — предлагает меню выбора одной из операций:

1. Рассчитать площадь фигуры.
2. Вывести определение фигуры.
3. Нарисовать фигуру.

Для выполнения каждой операции необходимо реализовать отдельную функцию.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало программы.
2. Подключение необходимых библиотек.
3. Объявление переменных и функций.
4. Ввод длины стороны треугольника `a`.
5. Проверка введённого значения. Если `a` меньше или равно нулю, вывести сообщение об ошибке и завершить программу.
6. Вывод меню с доступными операциями.
7. Ввод номера выбранной операции.
8. Проверка выбранного пункта меню с помощью оператора `switch`:
   - если выбран пункт 1, вызвать функцию `area()` для расчёта площади;
   - если выбран пункт 2, вызвать функцию `definition()` для вывода определения равностороннего треугольника;
   - если выбран пункт 3, вызвать функцию `draw()` для построения треугольника;
   - если выбран пункт 0, завершить программу;
   - если введено другое значение, вывести сообщение об ошибке.
9. Повторный вывод меню, если пользователь не выбрал выход.
10. Конец программы.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#include <math.h>

#define SYMBOL '*'

float area(float a);
void definition();
void draw(int a);

int main()
{
    setlocale(LC_ALL, "Russian");

    int choice;
    int a;

    printf("Введите длину стороны треугольника: ");
    scanf("%d", &a);

    if (a <= 0)
    {
        printf("Ошибка! Длина стороны должна быть положительной.\n");
        return 1;
    }

    do
    {
        printf("\nМЕНЮ\n");
        printf("1. Рассчитать площадь\n");
        printf("2. Вывести определение фигуры\n");
        printf("3. Нарисовать фигуру\n");
        printf("0. Выход\n");

        printf("Выберите операцию: ");
        scanf("%d", &choice);

        switch (choice)
        {
            case 1:
                printf("Площадь треугольника: %.2f\n", area(a));
                break;

            case 2:
                definition();
                break;

            case 3:
                draw(a);
                break;

            case 0:
                printf("Завершение программы.\n");
                break;

            default:
                printf("Неверный пункт меню!\n");
        }

    } while (choice != 0);

    return 0;
}

float area(float a)
{
    return (a * a * sqrt(3)) / 4;
}

void definition()
{
    printf("\nРавносторонний треугольник — это треугольник,\n");
    printf("у которого все три стороны равны,\n");
    printf("а все три угла составляют 60 градусов.\n");
}

void draw(int a)
{
    int i, j;

    for (i = 1; i <= a; i++)
    {
        for (j = 1; j <= a - i; j++)
        {
            printf(" ");
        }

        for (j = 1; j <= 2 * i - 1; j++)
        {
            if (i == a || j == 1 || j == 2 * i - 1)
            {
                printf("%c", SYMBOL);
            }
            else
            {
                printf(" ");
            }
        }

        printf("\n");
    }
}
```

## 3. Результаты работы программы

Для проверки программы была введена длина стороны треугольника `a = 5`.

**Проверка первой операции — расчёт площади:**

```text
МЕНЮ
1. Рассчитать площадь
2. Вывести определение фигуры
3. Нарисовать фигуру
0. Выход

Выберите операцию: 1
Площадь треугольника: 10.83
```

Площадь равностороннего треугольника рассчитывается по формуле:

S = (a * a * √3) / 4

При `a = 5` получаем:

S = (5 * 5 * √3) / 4 ≈ 10.83

**Проверка второй операции — вывод определения фигуры:**

```text
Выберите операцию: 2

Равносторонний треугольник — это треугольник,
у которого все три стороны равны,
а все три угла составляют 60 градусов.
```

**Проверка третьей операции — построение фигуры:**

```text
Выберите операцию: 3

    *
   * *
  *   *
 *     *
*********
```

**Проверка выхода из программы:**

```text
Выберите операцию: 0
Завершение программы.
```

В результате проверки установлено, что программа корректно выполняет все три операции. Пользователь может выбирать необходимые действия из меню несколько раз, а завершить работу программы можно с помощью пункта 0.
